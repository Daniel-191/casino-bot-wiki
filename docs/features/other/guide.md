# /guide

Your starting point in Paradise. New players get a short guided tour; everyone else gets a compact topic browser.

## Usage

`/guide`

## First time? You get the tour

If you've never run `/guide` before, it opens a **seven-screen tour** instead of the full guide. Each screen covers one idea and suggests one command to try, so there's nothing to memorise.

| Screen | What it covers |
|---|---|
| 1. Welcome to Paradise | What the bot is, and claiming your first [`/daily`](../../economy/earning/daily.md) |
| 2. Keep what you earn | Wallet cash is robbable, bank cash isn't — use [`/deposit`](../../economy/money-management/deposit.md) |
| 3. The casino floor | How a bet works, four games worth starting on, and the bet limits |
| 4. Earning money | The four jobs — [`/fries-in-bag`](../restaurants/fries.md), [`/farming`](../farming/index.md), [`/mine dig`](../mining/dig.md), [`/fish`](../fishing/fish.md) — and why gear matters |
| 5. The one habit that pays | [`/vote`](../../economy/earning/vote.md) builds a streak that multiplies nearly every reward |
| 6. Quests | Daily and weekly objectives, the [combo multiplier](../quests/quests.md) and the [quest shop](../quests/shop.md) |
| 7. Go have fun | Three directions to head in, plus the commands worth keeping handy |

The last screen has an **Open the full guide** button that drops you straight into the topic browser.

The bot remembers that you've seen the tour, so `/guide` opens the topic browser from then on. You can replay the tour any time with the **Take the quick tour** button on the guide's home screen.

## The full guide

Five topics, each a short read. Pick one from the dropdown.

| Topic | Covers |
|---|---|
| **Money Basics** | Wallet vs bank, vault upgrades, `/balance`, `/networth`, `/pay`, `/leaderboard` |
| **Earning Money** | Voting and streaks, the free reward commands, the five jobs |
| **Games** | Casino games, multiplayer games, sports betting, bet limits |
| **Long-Term Goals** | Properties, quests, pets, heists, lottery, scratch cards |
| **Help & Support** | This wiki, the Discord, bug reports, Patreon |

The guide deliberately stays brief. Exact payouts, price tables, streak multipliers and drop rates all live on this wiki — the guide links out to the relevant page rather than reprinting the numbers.

## Buttons

- **Wiki** — opens this wiki
- **Discord** — opens the [support server](https://discord.gg/vMcbru7qMV)
- **Back to topics** — returns to the home screen

## Notes

- No cooldown.
- The view belongs to whoever ran the command, and times out after 10 minutes.
- For a flat list of free-money commands, see [`/freemoney`](freemoney.md).
- For a browsable list of games, see [`/games`](games.md).
- For the full command list, use `/help`.
